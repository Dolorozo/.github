## 🤝 Contributing
1. **Fork** the repo & create a feature branch.  
2. Add your link under the correct section *(alphabetical order please)*.  
3. Commit using conventional commits (e.g. `feat(services): add MyCoolHost`).  
4. Open a Pull Request – describe why your entry belongs here.  
5. ❤️ Thank you for making the Monero ecosystem more discoverable!

> **Entry rules**  
> • Must accept or build on Monero.  
> • Open-source code repos preferred (★ ≥ 1).  
> • No referral links, affiliate spam, or obvious scams.  
> • Deprecated / dead projects will be periodically pruned.
